# TimelyTrim-Flutter

## Overview

Mobile app to book your hair dresser in advance and save your time

This mobile app, developed as part of a university assignment, is built with Flutter and is available for testing and review.

Follow this README to set up the necessary environment on your machine and run the app in debug mode.

### Repository Link

https://github.com/JazebJaved468/TrimTime-Flutter/tree/develop

---

## Prerequisites

1. **Operating System**: Compatible with macOS, Windows, or Linux.
2. **Disk Space**: Minimum 2GB for the Flutter SDK and additional space for dependencies.
3. **Android Device or Emulator**: To test the app.

---

## Step-by-Step Setup Guide

### 1. Install Flutter SDK

1. **Download the Flutter SDK**: [Flutter SDK download page](https://flutter.dev/docs/get-started/install)
2. **Extract the File**: Unzip the downloaded file to a desired location on your system (e.g., `C:\flutter` on Windows, or `~/flutter` on macOS/Linux).
3. **Update Path**:
   - Add the Flutter SDK to your system path:
     - **Windows**: Add `flutter/bin` directory to your environment variables.
     - **macOS/Linux**: Run the following in your terminal:
       ```bash
       export PATH="$PATH:`pwd`/flutter/bin"
       ```

### 2. Run Flutter Doctor

Open a terminal or command prompt and run the command:

```bash
flutter doctor
```

### 3. Install Android Studio

https://docs.flutter.dev/get-started/install/windows/mobile

### 4. Clone the Repository

git clone https://github.com/JazebJaved468/TrimTime-Flutter.git
cd TrimTime-Flutter

### 5. Install Project Dependencies

```bash
flutter pub get
```

### 6. Running the App in Debug Mode

```bash
flutter run
```

### 7. Running the Release Build

Download the APk file from the below google drive link and install it on your android device.

https://drive.google.com/drive/u/1/folders/1RJHVgdfIpDwHfT1VzNu9Zr6OCS2tIDit?dmr=1&ec=wgc-drive-globalnav-goto

# Developer Notes

- Kindly make a new branch for every new feature you are working on.
- Make sure to pull the latest changes from the 'develop' branch before creating a new branch.
- After completing the feature, create a pull request to merge your branch with the 'develop' branch.
- After merging the feature, delete the branch you created for the feature.
- sync your local develop branch with the remote develop branch before starting a new feature.

- important : Do not push directly to the 'develop' branch.
